# しるし / Shirushi

**作品に利用意思を残す**

Shirushi v0.1 Previewは、画像へAI利用に関する意思を機械可読な形式で記録し、後から確認できるWindows向けツールです。

C2PA、CAWG Rights、TrustMarkを利用しています。これらの仕様を詳しく知らなくても、GUIから画像を選び、意思表示の付与と確認を行えます。

## Release版を起動する

Shirushi v0.1 Previewの配布パッケージは、Windows x64向けのZIP形式です。インストーラーは使用しません。

1. `shirushi-v0.1-preview-windows-x64.zip`を入手します。
2. ZIPファイルを右クリックして`すべて展開`を選び、任意の場所へ展開します。
3. 展開したフォルダー内の`Shirushi.exe`をダブルクリックします。

ZIP内から直接起動せず、必ず展開したフォルダー内の`Shirushi.exe`を使用してください。`Shirushi.exe`だけを別の場所へ移動せず、展開したフォルダーはそのままの構成で使用してください。

現行の`Shirushi.exe`にはWindowsのコード署名を行っていません。Windowsが発行元を確認できない旨を表示した場合は、入手元とファイルを確認し、信頼できる場合だけ実行してください。

## Shirushiでできること

- 画像を選ぶ
- 「AIによる学習・生成利用を希望しない」という意思を記録する
- 元画像を上書きせず、別ファイルとして保存する
- 保存した画像や受け取った画像に、どのような情報が記録されているかを後から確認する
- C2PA、CAWG Rights、TrustMarkなどを使って情報を記録・確認する
- 既存のしるし情報がある場合、再付与の前に警告する

## Shirushiが保証しないこと

ただし、すべてのAIサービスがこの権利情報を読み取り、その意思表示を尊重するとは限りません。
また、AI学習やAI生成を直接停止する機能ではありません。

Shirushiは、利用者が著作権者本人であることを確認せず、記録した情報の法的効力も保証しません。Production Trustには対応していません。

`意思表示の認識 ≠ 実際の遵守` — 意思表示が認識されることと、実際に守られることは別です。

この製品でできること・できないことの詳細は[製品上の注意事項](DISCLAIMER.md)を参照してください。

## 対応画像形式

| 形式 | 現行v0.1の対応 |
| --- | --- |
| PNG | しるしの付与・確認 |
| JPEG / JPG | しるしの付与・確認 |

しるしを付けて保存するファイルの拡張子は、現行実装では`.png`、`.jpg`、`.jpeg`です。

## 基本的な使い方

### しるしを付ける

現在のv0.1 Previewでは、`AIによる学習・生成利用を希望しない`という意思表示が固定で設定されています。

1. 画像を選択します。
2. `しるしを付ける`を選びます。
3. `✔ しるしを付けました`と保存ファイル名が表示されたことを確認します。

必要な権利または許諾を持つ画像に使用してください。元画像は直接上書きされません。

出力は、入力画像と同じフォルダーに`_rights`を付けた別ファイルとして保存されます。例えば、`photo.jpg`を選ぶと`photo_rights.jpg`が保存予定名になります。保存後は`保存先を開く`からフォルダーを開けます。

同じ名前の出力ファイルがすでにある場合、既存ファイルは上書きしません。別の名前で保存する機能は現行v0.1にはないため、既存ファイルを確認してからもう一度操作してください。

付与前に既存のしるし情報を確認します。すでにしるしが付いている場合、識別情報だけが残っている場合、または情報の完全性を確認できない場合は、警告して標準では処理を停止します。明示的に続行した場合だけ再付与しますが、既存情報に影響する可能性があります。

### しるしを確認する

この機能では、AI利用に関する意思表示を確認できる状態か、識別情報だけが残っている状態か、または情報を確認できない状態かを確認できます。

1. 画像を選択します。
2. `しるしを確認する`を選びます。
3. メイン画面内の確認結果を見ます。

## 確認結果

### 完全性を確認済み

記録されたAI利用に関する意思表示（CAWG Rights）、C2PA、TrustMarkなどについて、Shirushiが確認対象としている技術的な整合性を確認できた状態です。著作権者本人であることや、法的有効性を確認したという意味ではありません。

### 意思表示なし

Shirushiが対象の権利情報を確認できなかった状態です。利用の`許可`でも`拒否`でもありません。

### 識別情報のみ

TrustMarkなどの識別情報が残っている可能性はありますが、AI利用条件そのものは確認できない状態です。

### 確認できません

情報が存在する可能性はあるものの、完全性を確認できない状態です。意思表示が見つからない状態とは区別されます。

## Preview署名

Shirushi v0.1 Previewの現行署名には開発・テスト用の資格情報を使用しています。Production Trustではなく、作者本人であることや著作権の保有を証明するものではありません。

署名と確認結果の詳しい意味は[製品上の注意事項](DISCLAIMER.md)を参照してください。

## プライバシーとネットワーク

画像の付与・確認処理は基本的にローカルで行い、Shirushi自身には画像ファイルを外部サービスへアップロードする処理はありません。

TrustMarkモデルの取得時や、外部C2PA参照情報を含む画像の確認時には通信が発生する可能性があります。利用状況の分析、製品テレメトリ、リモートログ送信は実装していません。

通信、ログ、一時ファイル、キャッシュの詳細は[プライバシー情報](PRIVACY.md)を参照してください。

## 初回利用時の準備

TrustMarkのモデルファイルはShirushiの配布物に同梱しません。しるしの付与または確認で必要なモデルがない場合は、公式の配布元から自動取得し、ユーザー用キャッシュへ保存します。初回準備にはインターネット接続が必要です。手動配置は不要です。

準備中は画面に`初回準備中`と`初回のみ時間がかかる場合があります。しばらくお待ちください。`が表示されます。画面を閉じず、そのまま完了を待ってください。一度正常に取得したモデルは、以後の利用でユーザー用キャッシュから読み込みます。

Shirushiは、モデル取得要求へ画像データを渡しません。保存場所などの詳細は[プライバシー情報](PRIVACY.md)に記載しています。

## メタデータと情報の残存性

再保存、形式変換、SNSへのアップロード、メタデータの削除、切り抜き、サイズ変更、回転、他の画像編集ソフトによる加工で、権利情報やメタデータの一部または全部が失われる可能性があります。

Shirushiも入力画像のすべてのメタデータを完全に保存するものではありません。重要な元画像は保持してください。詳しくは[製品上の注意事項](DISCLAIMER.md)を参照してください。

## 開発者向けの起動方法

以下は開発者向けです。通常利用では不要です。一般ユーザーは、前述の配布パッケージに含まれる`Shirushi.exe`を使用してください。

標準の開発環境はWindows、Python 3.12系、リポジトリのチェックアウト、`.venv-py312`を使用します。必要な環境を準備したリポジトリのルートで`Shirushi.vbs`をダブルクリックすると、コンソール画面を表示せずにGUIを起動できます。
