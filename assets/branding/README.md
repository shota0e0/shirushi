# Product branding assets

These three existing public assets identify the Shirushi product. They are not
test fixtures, documentation images, or sample Personal Marks:

- `assets/app_icon.png`
- `assets/app_icon.ico`
- `assets/branding/shirushi-app-icon-master.png`

They are retained unchanged from public base
`2884b6c4da1339778ae4678ddae159a4100fa130`. No new image is introduced here.
Classification is by these exact paths, not by an exemption for all of `assets/`.
The public asset governance test separately enumerates documentation, demo art,
and image fixtures and retains their existing provenance and attribution.

## Current use boundary

The repository's source-code license and the use of product branding for
identification, endorsement, or trademark-like purposes are not automatically
the same question. This document records the assets' role and existing use in
Shirushi; it does not determine a new license, grant additional branding use,
claim a new legal right, or assert trademark registration or exclusivity.
Any separate branding-use terms require an explicit, separately reviewed
statement; no such new terms are introduced by this export.
