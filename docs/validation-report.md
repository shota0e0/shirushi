# しるし / Shirushi v0.1 Preview ローカル検証結果

この文書は、固定したローカル検証環境で、Shirushi v0.1 Previewの付与・保存・確認機能について実際に確認した内容をまとめたものです。

検証はWindows上のローカル環境で行いました。外部AIサービスが記録情報を認識、解釈、遵守するかどうかは、この文書の評価対象に含みません。

## 1. 検証の目的と範囲

Shirushiは、画像へAI利用に関する意思表示を機械可読な形式で記録し、後から確認できるようにするツールです。

今回のローカル検証では、主に次の点を確認しました。

- AI利用に関する意思表示を画像へ記録できるか
- 付与した画像を元画像とは別のファイルとして保存できるか
- 保存後の画像から記録内容を確認できるか
- PNGおよびJPEGで基本的な付与・確認の流れが成立するか
- 画像の加工後に、記録情報や識別情報の状態がどのように変わり得るか

この検証は、外部AIサービスの挙動、AI利用の防止、法的効力、作品の保護性能を確認するものではありません。

## 2. 検証対象と方法

対象はShirushi v0.1 Previewです。固定したWindowsローカル環境で、プロジェクト内で生成した合成画像を中心に検証しました。

追加確認として、所定の項目についてプライバシー上の確認を行ったJPEG画像も使用しました。ただし、このJPEG確認は限定された画像を対象としたものであり、実世界のあらゆるJPEG画像を代表するものではありません。

基本的な確認手順は次のとおりです。

1. 対象画像を選択する
2. ShirushiでAI利用に関する意思表示を記録する
3. 元画像を上書きせず、別の画像ファイルとして保存する
4. 保存した画像をShirushiで読み直す
5. 記録内容と画像との技術的な整合性を確認する

このほか、情報が記録されていない画像、識別情報だけが確認できる画像、情報の完全性を確認できない画像についても、表示状態を確認しました。

## 3. PNG／JPEGでの付与・保存・確認

固定したローカル検証環境では、PNG画像に対する次の基本動作を確認しました。

- AI利用に関する意思表示を記録する
- 元画像とは別のファイルとして保存する
- 保存後の画像をShirushi自身の確認処理で読み取る
- 記録内容と画像との技術的な整合性を確認する

JPEG／JPGについても、同じ基本的な付与・保存・確認の流れが成立することを確認しました。

Shirushiは元画像を直接上書きしません。処理結果は別の画像ファイルとして保存されます。

プロジェクト内で生成した合成PNGを使った複数回の実行でも、それぞれの出力について記録と保存後の確認が成立しました。これは、固定した検証条件で同じ基本フローが繰り返し成立したことを示します。

## 4. 確認結果の状態分類

Shirushiは、画像から確認できた情報を次の4つの状態に分けて表示します。

### 完全性を確認済み

記録されたAI利用に関する意思表示（CAWG Rights）、C2PA、TrustMarkなどについて、Shirushiが確認対象としている技術的な整合性を確認できた状態です。

これは、作者本人、著作権者本人、著作権の保有、法的有効性、Production Trustを確認したという意味ではありません。

### 意思表示なし

Shirushiが対象のAI利用に関する意思表示を確認できなかった状態です。

この状態は、AI利用の許可も拒否も意味しません。対象の情報が記録されていない場合のほか、Shirushiが確認できる形で情報が残っていない場合もあります。

### 識別情報のみ

TrustMarkなどの識別情報が確認できるものの、対応するAI利用条件全体を確認できない状態です。

識別情報を検出できたことと、AI利用に関する意思表示や利用条件を確認または復元できたことは別です。

### 確認できません

情報が存在する可能性はあるものの、その内容や完全性を確認できない状態です。

この状態は、AI利用に関する意思表示が見つからない「意思表示なし」と区別されます。

## 5. 加工後の情報残存性

加工後の情報残存性については、Shirushi本体の基本動作確認とは別に、固定した検証用画像と確認環境を用いて観測しました。次のような加工後に、記録情報および識別情報の状態を確認しました。

- JPEG圧縮
- サイズ変更
- 切り抜き
- 回転
- 画像の重ね合わせ
- 再保存に相当する処理

確認した範囲では、加工条件によって識別情報が残る場合と、失われる場合の両方がありました。

また、メタデータ側に記録された情報と、画素側に付与された識別情報では、加工後に異なる状態になる場合がありました。どちらか一方、または両方が失われる場合もあります。ただし、画素側の識別情報だけが残っていても、AI利用に関する意思表示の内容全体を確認または復元できたとは扱いません。

この結果は、特定の加工条件に対する耐久性を保証するものではありません。使用するソフトウェア、保存方法、画像形式、加工内容などによって結果が変わる可能性があります。

## 6. ローカル検証で確認できたこと

固定したローカル検証環境では、次の事項を確認しました。

- PNGおよびJPEGで、付与・別ファイル保存・保存後確認の基本フローが成立した
- 固定した検証条件で、合成PNGを用いた複数回の実行において記録と保存後確認が成立した
- 確認結果を「完全性を確認済み」「意思表示なし」「識別情報のみ」「確認できません」の4状態に区別できた
- 識別情報だけが残る状態と、AI利用に関する意思表示を確認できる状態を区別できた
- 加工後の情報残存性は一律ではなく、識別情報が残る場合と失われる場合があった
- メタデータ側の記録と画素側の識別情報が、加工後も同じように残るとは限らなかった

これらは、Shirushi v0.1 Previewのローカルでの基本動作・確認結果の扱いの検証と、それとは別に行った加工後の情報残存性の技術観測をまとめたものです。

## 7. 検証の限界とv0.1 Previewの位置づけ

今回の結果は、固定したローカル検証環境で確認した範囲に限られます。すべての画像、Windows環境、画像編集ソフト、保存方法、加工条件で同じ結果になることを示すものではありません。

また、この検証からは次の事項を判断できません。

- 外部AIサービスが記録情報を認識するか
- 外部AIサービスがAI利用に関する意思表示を正しく解釈するか
- 外部AIサービスがその意思表示を尊重するか
- AI学習やAI生成を停止できるか
- 記録した情報が法的効力を持つか
- 利用者が作者本人または著作権者本人であるか
- 利用者が著作権を保有しているか
- Production Trustを備えた署名であるか
- あらゆる加工後に情報が残るか

Shirushi v0.1 Previewは、AI利用に関する意思表示を画像へ記録し、対応する情報を後から確認するためのPreview版です。今回のローカル検証は、その基本的な付与・保存・確認処理が、固定した条件で成立することを確認したものです。

C2PA、CAWG Rights、TrustMarkの役割や、v0.1 Previewの署名と信頼性の扱いについては、[技術概要](technical-overview.md)を参照してください。

外部AIサービス側での認識、解釈、生成挙動については、再現可能な証拠が固定された場合に、ローカル検証とは分けて扱う可能性があります。
